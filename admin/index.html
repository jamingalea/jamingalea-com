Connect to GitHub

Publishing commits your changes to the site's GitHub repository. Vercel then redeploys the site automatically (usually within a minute).

How to create a token
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this site's repository.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate, copy the token and paste it above.

The token is saved only in this browser on this device. Use “Forget token” on shared computers.
